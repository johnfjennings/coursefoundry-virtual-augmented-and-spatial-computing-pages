Week 10 Lab

Spatial Audio and Haptics on Device

1 Lab Overview

Duration: 2 hours Hardware: Meta Quest 3 / 3S (Quest 2 acceptable), headphones or the headset’s built-in speakers Software: Unity 2022 LTS, XR Interaction Toolkit 2.x, Meta XR Audio SDK Starting point: your Assessment 3 project, with its core interaction Deliverable: Assessment 3 milestone demonstrated on device, and a technical note (150–250 words) for your Assessment 1 portfolio

This lab is where the Assessment 3 Week 10 milestone is demonstrated: your core interaction working on device, with synchronised spatial audio and haptic feedback.

2 Learning Objectives

By the end of this lab you will be able to:

  • Configure a spatialiser, attenuation and room acoustics matched to scene geometry
  • Drive haptic feedback from XR Interaction Toolkit interaction events
  • Synchronise audio, haptic and visual feedback to interaction state

3 Part 1: Spatialised Audio (40 min)

3.1 Task 1.1 — Install and Enable the Spatialiser

  1. Install the Meta XR Audio SDK (from the Unity Asset Store or Meta’s package registry, following Meta’s install instructions).
  2. Open Edit > Project Settings > Audio and set Spatializer Plugin to Meta XR Audio. If the SDK asks you to set an ambisonic decoder, set that as well.
  3. Restart the editor if prompted.

3.2 Task 1.2 — Place Spatialised Sources

  1. Choose two or three sounds that come from objects in your scene: the object of your core interaction, something that hums or ticks, a door. Use mono clips: a stereo clip cannot be placed at a point.
  2. On each object’s Audio Source, set Spatial Blend to 1 (3D) and tick Spatialize. Add the SDK’s audio source component if its documentation asks you to.
  3. Trim each clip so the sound starts on the first sample. Silence at the start of a clip is latency you added yourself.

3.3 Task 1.3 — Tune Attenuation by Ear

  1. In the Audio Source’s 3D Sound Settings, try Logarithmic and Linear rolloff and adjust Min Distance and Max Distance.
  2. Do this in the headset: walk towards and away from each source. Does it sound as far away as it looks? Is the important sound still audible where the user will stand?

3.4 Task 1.4 — Match the Room

  1. Use the Meta XR Audio SDK’s room acoustics settings to describe a room roughly the size and material of your scene (follow the SDK documentation for the current component name).
  2. Listen in the headset with room acoustics off and on. Does the sound now belong to the space you can see?

If you are not using a spatialiser plugin, an Audio Reverb Zone with a matching preset does a similar job. Use one approach or the other, not both.

4 Part 2: Haptics (35 min)

4.1 Task 2.1 — Event Haptics Without Code

  1. Select the controller interactors in your XR Origin (for example the XR Ray Interactor or XR Direct Interactor on each controller).
  2. In the Inspector, find the haptic settings (Haptic Events: Play Haptics On Select Enter, On Hover Enter and so on) and enable them for select and hover, with an intensity (0–1) and duration in seconds for each.
  3. Start subtle: hover around 0.1 for 0.02 s, select around 0.5 for 0.05 s.

4.2 Task 2.2 — Scripted Haptics for Your Interaction

For events the Inspector settings do not cover (an impact, a lock clicking shut), send an impulse from your own script. In XR Interaction Toolkit 2.x, the interactor that triggered the event can send it:

using UnityEngine;
using UnityEngine.XR.Interaction.Toolkit;

public class ImpactHaptic : MonoBehaviour
{
    [SerializeField, Range(0f, 1f)] float amplitude = 0.8f;
    [SerializeField] float duration = 0.08f;

    // Hook this to an interactable event, e.g. Select Entered on an XRGrabInteractable
    public void Pulse(SelectEnterEventArgs args)
    {
        if (args.interactorObject is XRBaseControllerInteractor controllerInteractor)
            controllerInteractor.SendHapticImpulse(amplitude, duration);
    }
}

4.3 Task 2.3 — Vary by Event

Give at least three events in your interaction different haptics, using the Week 10 vocabulary: a light touch (low amplitude, short), a heavy impact (high amplitude, short), and something continuous if your interaction has one (for example a low pulse repeated while dragging). Write down why each pattern fits its physical cause.

4.4 Task 2.4 — Confirm on Device

Haptics cannot be evaluated in the editor or a simulator. Build and run, and check each pattern in the headset. Hand tracking has no haptics: if your project uses hands, make sure audio and visuals carry the feedback instead.

5 Part 3: Synchronised Feedback (45 min)

5.1 Task 3.1 — One Event, Three Responses

For each key moment in your core interaction (grab, use, release, impact), wire the visual response (highlight, animation, particle), the audio and the haptic to the same interaction event, for example the same Select Entered UnityEvent. Avoid triggering any of them from a separate timer or a later frame.

5.2 Task 3.2 — Check They Arrive Together

In the headset, perform each key moment slowly and then quickly. Do the visual, sound and vibration feel like one event? If not:

  • Trim leading silence from the audio clip
  • Make sure all three are triggered from the same event
  • Check that no animation has a delay or a slow start

Ask a classmate to try it too: they will notice a mismatch you have stopped hearing.

  • A short headset capture of your core interaction with sound on
